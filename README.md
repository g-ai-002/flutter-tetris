# 俄罗斯方块 🧱

基于 Flutter + Flame 的国风俄罗斯方块，支持 Android、Windows 与 Web。采用 Guideline 规则，内置五种玩法、四套国风皮肤、12 关关卡挑战、每日挑战、键位自定义与手柄支持、本地纪录、程序化音效与五声音阶背景音乐，全程离线运行。

## 功能

- 🎮 五种玩法：经典无尽、40 行竞速、2 分钟计时、12 关关卡挑战、每日挑战
- 🧩 现代规则：10×20 场地、7 包随机、SRS 旋转与踢墙、500ms 锁定延迟
- 👻 手感细节：五个预览、幽灵落点、暂存（每次落定限一次）、软降与硬降
- 🏆 计分体系：单/双/三/四行、T-Spin 与 Mini、连续奖励、连击、全消奖励、15 级提速
- 🗺️ 关卡模式：预设地形、周期性垃圾行上涌、限时目标、逐关解锁与三星评价
- 📅 每日挑战：本地日期派生种子，三端牌序一致，记录当日最高分与连续打卡，可复制战报
- 🔁 种子回放：纪录页保留最近七天，点任一天即可用当日种子重玩
- ✨ Flame 渲染：立体方块、消行闪光与碎屑粒子、硬降拖影、顶部危险线、石灰垃圾块
- 🎨 四套棋盘皮肤：宣纸 / 青瓷 / 敦煌 / 水墨，棋盘底色、方块配色与界面强调色同步切换
- ⌨️ 键盘操作：← → 移动、↓ 软降、空格硬降、↑/X 顺时针、Z 逆时针、C 暂存、P 暂停、R 重开
- 🎛️ 键位自定义：九项操作逐项改键、冲突自动交换、恢复默认，偏好持久化
- 🕹️ 手柄支持：标准布局 USB / 蓝牙手柄即插即用，左摇杆与十字键长按连发
- 📱 触屏操作：点击旋转、左右拖动移动、下滑软降、上滑暂存，并提供六键触控区
- 🗂️ 本地纪录：各模式最高分、竞速最快用时、关卡星级、每日成绩、累计对局 / 消行 / 得分
- 🔔 程序化音频：10 种运行时合成音效 + 16 秒五声音阶循环，音效 / 音乐 / 震动独立开关
- 🈶 简体中文界面、深色模式，Windows 优先 Microsoft YaHei UI，Web 使用 soup_fonts 思源黑体
- 📐 响应式布局：手机 / 折叠屏 / 平板 / Windows 窗口自适应，宽屏三栏、窄屏单栏
- 🧾 日志按天写入用户目录，设置页可查看最近日志并打开所在目录

## 开发

```bash
flutter pub get
flutter analyze
flutter test
```

构建产物由 CI 生成：在 GitHub Actions / Gitea Actions 里手动运行 `build` 工作流，选中 `v*` Tag 时按该 Tag 的版本构建 Android / Windows / Web 并发布 Release，运行 `main` 则产出预览产物。音频在运行时合成、Web 字体来自 soup_fonts，仓库不存放字体与音频文件。手柄输入使用 `gamepads` 插件，Android 端由 `MainActivity` 转发按键与摇杆事件；本地无需安装 Android SDK 等大型工具链。

## 操作说明

| 操作 | 键盘（可在设置中改键） | 手柄 | 触屏 |
| --- | --- | --- | --- |
| 左右移动 | ← / → | 左摇杆 / 十字键左右 | 左右拖动或「左移 / 右移」 |
| 软降 | ↓ | 左摇杆下 / 十字键下 | 向下拖动或「软降」 |
| 硬降 | 空格 | Y / RB / 十字键上 | 「硬降」 |
| 顺时针旋转 | ↑ / X | A | 点击棋盘或「旋转」 |
| 逆时针旋转 | Z | B | 「旋转」 |
| 暂存 | C / Shift | X / LB | 上滑或「暂存」 |
| 暂停 | P / Esc | Start | 顶栏暂停按钮 |
| 重新开始 | R | — | 暂停菜单 |

支持 Xbox、PlayStation 及标准布局的 USB / 蓝牙手柄；未连接手柄时键盘与触屏不受影响。

## 日志位置

- Windows：`文档/FlutterTetris/logs/app_yyyyMMdd.log`
- Android：应用外部存储目录下的 `FlutterTetris/logs/`
- Web：仅保留内存日志，可在设置页查看

## 目录结构

```
lib/
├── game/       方块定义、场地、关卡、7 包随机、SRS、计分板、模式与对局控制器
├── input/      键位模型、持久化编解码与手柄输入映射
├── flame/      Flame 场地组件与游戏入口（粒子、消行、拖影）
├── pages/      首页、关卡选择、对局页、设置页、纪录页与通用组件
├── services/   日志、偏好与纪录存储、文件系统、音效合成与播放
├── providers/  设置状态
├── theme/      皮肤与配色主题、方块笔触、玩法视觉映射
└── utils/      常量、格式化、平台判断、窗口初始化
```
